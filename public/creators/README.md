# Creator portraits

## Exact crop for the circle

Avatars are perfect circles. Export each photo as a **square**:

| Spec | Value |
|------|--------|
| Shape | Circle (masked from a square) |
| Aspect ratio | **1:1** |
| Recommended size | **800 × 800 px** (min 512 × 512) |
| Format | `.jpg` / `.webp` / `.png` |
| Framing | Keep face / logo centered — corners of the square are cut off by the circle |

Safe area: keep important content inside the **center circle** of the square (about the middle 70% diameter). Edges/corners get cropped.
